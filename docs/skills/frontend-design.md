# Frontend Design & Aesthetics (Emergency Tradesmen)

This guide enforces the premium aesthetic standards for all frontend work in the `emergency-tradesmen` project.

## Core Aesthetic: "Premium Utility"
We avoid generic designs. Every component must feel intentional, high-end, and authoritative.

## Non-Negotiables
- **Typography First**: Use `font-display` for all headings. Never rely on default weights; use `font-bold` or `font-medium` to establish hierarchy.
- **Hierarchy over Borders**: Use negative space and font sizing rather than boxes and cards.
- **Micro-Animations**: All interactive elements (buttons, links) must have subtle transitions (e.g., `transition-all duration-300`).
- **Color Discipline**: Use the `#gold` (#FFD700) accent sparingly but effectively for trust and premium feel.
- **Dark Mode Excellence**: Ensure high contrast and accessibility while maintaining a sophisticated dark theme.

## Scroll Experience Rules
- **No Repeated Entrances**: Stagger animations so elements don't appear simultaneously.
- **Large Typography**: Use massive headings for impact in scroll-driven sections.
- **Asymmetric Layouts**: Break the grid to guide the eye and create interest.
