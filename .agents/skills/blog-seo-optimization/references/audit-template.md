# Blog Audit Template

Use this table per post.

| Field | Required | Notes |
|---|---|---|
| URL | Yes | Final canonical URL |
| Domain | Yes | emergencytradesmen.net or emergencycontractors.net |
| Country intent | Yes | UK or US |
| Primary keyword | Yes | One core target phrase |
| Secondary keywords | Yes | 3-8 semantically related terms |
| Search intent | Yes | Informational / Commercial / Transactional / Local service |
| Word count | Yes | Flag if thin for topic depth |
| Title tag | Yes | Unique + keyword front-loaded |
| Meta description | Yes | Clear value proposition + location cue |
| H1 quality | Yes | One H1 only |
| H2/H3 structure | Yes | Covers sub-intents and FAQs |
| Internal links out | Yes | Links to service + related blog pages |
| Internal links in | Yes | At least one contextual inbound link |
| External sources | Optional | Add for regulations/safety/statistics |
| Duplicate cluster | Yes | Topic overlap grouping ID |
| Schema | Optional | Article/FAQ/Breadcrumb if supported |
| Localization score | Yes | Terminology + spelling + regulation alignment |
| AI Overview readiness | Yes | Direct answer blocks + scannability |

## Severity Rubric

- **Critical**: Wrong domain, wrong canonical, major intent mismatch, duplicate cannibalization.
- **High**: Missing primary keyword, broken heading hierarchy, weak internal linking.
- **Medium**: Underdeveloped sections, weak FAQ/snippet formatting, insufficient citations.
- **Low**: Minor phrasing/meta tuning.

## Definition of Done (Per Post)

A post is complete only if:

1. Country intent and domain are correct.
2. Primary and secondary keyword mapping is explicit.
3. H1-H3 hierarchy is clean and readable.
4. Content is substantial, unique, and intent-matched.
5. Internal links connect to service pages and related posts.
6. Localization and regulations match the target market.
7. Snippet/AI Overview extraction opportunities are present.
